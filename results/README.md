# results/ — output directory

This directory holds the outputs produced by `scripts/`. Code, data, and
results are kept separate:

- `scripts/` — all analysis code (numbered in pipeline order, see the top-level README)
- `data/`    — created by you after downloading the public accessions (NOT in this repository)
- `results/` — everything the scripts write

## What is committed here

Only the small, submission-grade derived tables are committed:

```
results/tables/   Table 1–3 and S1–S5 of the manuscript (csv + xlsx)
```

`TableS1_rep30_genes.csv` is the csv form of the corresponding xlsx (it is
also read back by `scripts/21_rep52_percohort_performance.py`).

## What the scripts write when you rerun the pipeline

Everything else is generated locally and should not be committed:

```
results/
├── rep30/                  REP30 score construction (Cox weights, 30-gene panel)
├── rep52_trim/             panel trimming / backtest outputs
├── manuscript_support/     audit outputs: null benchmarks, C-index cost,
│                           transfer stability, proliferation control, sensitivity demo
├── metastatic/             AURORA / MET500 / MBCproject validation outputs
├── figures/                Figures 1–4 and S1–S4 (PDF/EPS/PNG), written by
│                           scripts/60_build_manuscript_figures.py and scripts/61_export_panels.py
└── tables/                 the committed submission tables (regenerated by scripts/59_build_tables.py)
```

Suggested `.gitignore` additions when you rerun locally:

```
results/rep30/
results/rep52_trim/
results/manuscript_support/
results/figures/
data/
```
